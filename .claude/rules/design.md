# Design

Follow the design principles in `docs/DESIGN.md`. Key points:

- **Linear-inspired**: Minimal, sharp, keyboard-first
- **Compact density**: Maximize visible content
- **Ghost buttons**: Text-only by default, filled only for critical CTAs
- **Hairline borders**: 1px borders, minimal shadows
- **Quick transitions**: 100-150ms, no decorative animations
- **Outline icons**: Heroicons outline variant, 1.5px stroke
- **Sharp corners**: `rounded` (4px) for most elements
- **Semantic colors**: Use tokens (`bg-background`, `text-primary`), never raw hex
